# 💖 Para ti, mi flaca hermosa

Este proyecto es una pequeña página web romántica creada con **HTML, CSS y JavaScript**.
Está pensada como un detalle especial para alguien importante, mostrando un mensaje animado y un botón que lleva a una sorpresa.

## ✨ Características

* Efecto **typewriter** (máquina de escribir) para mostrar un mensaje especial.
* Diseño simple y romántico.
* Botón interactivo que dirige a otra página con una sorpresa.
* Uso de **HTML**, **CSS** y **JavaScript** básico.

```
project/
```

## 🧩 Archivos principales

### `index.html`

Es la página principal donde se muestra:

* El mensaje romántico con efecto de escritura.
* Una pequeña dedicatoria.
* Un botón que redirige a `flower.html`.

### `style.css`

Contiene todos los estilos visuales de la página:

* Tipografía
* Colores
* Diseño del contenedor
* Estilos del botón

### `typewriter.js`

Script encargado de generar el **efecto de escritura** del mensaje en el título.

### `flower.html`

Página secundaria que contiene la sorpresa o animación adicional.

## 🚀 Cómo usar el proyecto

1. Descarga o clona el repositorio.
2. Abre la carpeta del proyecto.
3. Ejecuta el archivo:

```
index.html
```

Puedes abrirlo directamente en tu navegador.

## ❤️ Propósito

Este proyecto fue creado como un detalle especial para expresar cariño y hacer un momento memorable.
